# 🖥️ Sis2 Proyecto - Tienda de Computadoras "ArmaTech"

Este es un proyecto desarrollado en React con Vite como empaquetador. La tienda permite mostrar productos (como laptops y PCs de escritorio) con una interfaz simple y moderna.

## 🧾 Características

- 📦 Catálogo de computadoras
- 🧩 Componentes reutilizables (Navbar, ProductCard)
- 🖼️ Imágenes de productos desde `/assets`
- ⚛️ Construido con React y Vite
- 💻 Diseño adaptado para clases de Sistemas II



## 🛠️ Instalación

### 1. Clona el repositorio

```bash
git clone https://github.com/tuusuario/ArmaTech.git
cd armatech
```

### 2. Instala las dependencias

```bash
npm install
```

### 3. Inicia el servidor de desarrollo

```bash
npm run dev
```

Abre tu navegador en `http://localhost:5173/`

---

## 🚀 Construcción para producción

```bash
npm run build
npm run preview
```

---

## ✅ Requisitos

- Node.js `v18+`
- npm `v9+`
- Git (con Git Bash recomendado)
- Vite

---

## 📝 Notas adicionales

- El proyecto usa `vite` como servidor de desarrollo.
- El archivo `.gitignore` incluye `node_modules/`, `dist/`, `.env`, etc.
- Puedes subir este proyecto a GitHub aunque el `"name"` en `package.json` sea diferente al nombre del repositorio.
